# 모델 B 실험 — 선형 / XGBoost / MLP (2021-01 ~ 2026-09)

재현: `python scripts/train_model_b.py --model-a <모델A CSV> --reddit <ticker_day_sentiment.parquet>`
(코드: `src/capstone/models/model_b/experiment.py`). 이 문서는 집계 지표만 담고 있으며 Reddit 원문은 없다.

## 설정
- 데이터: 모델 A(Chronos-2) 예측 + 뉴스 피처 + Reddit FinBERT 피처, 공통 구간 2021-01-04 ~ 2026-09-30, 10종목 × 1,442거래일 = 14,420행.
  (모델 A·뉴스는 2026-10-30까지 있으나 Reddit이 09-30까지라 공통 구간만 사용)
- 타깃: `residual = real_ret − pred_ret` (3거래일 수익률 기준 모델 A의 오차)
- 피처: 뉴스 `n_articles_z, n_primary_z, sent_z, sent_z_primary`, Reddit `mention_rate_z, sent_mean_z, mention_x_sent_z, log(n_scored)`.
  z는 ±5로 자르고 결측은 0으로 채우되 결측 지표를 함께 넣는다.
- 모델: Ridge(RidgeCV), XGBoost(depth 2, 200그루, min_child_weight 50), MLP(32-16, early stopping). 시드 0, 튜닝 없음.
- 평가: walk-forward(확장 창) 5블록, 테스트는 뒤쪽 866거래일, 학습은 테스트 시작 3거래일 전까지(purge).
  지표는 날짜별 횡단면 Spearman IC, t값은 3일 수익률 겹침을 반영해 표본 수를 n/3으로 줄여 계산.

## 해석
- 모든 조합에서 ε IC가 0과 구분되지 않는다(|t| < 1.2).
- 최종 예측 IC가 모델 A 단독(0.0387)보다 나아진 조합이 없다. 최고인 Reddit+XGBoost(0.0398)도 사실상 같다.
- `r2_oos_eps`(0 예측 대비)가 양수로 나오는 것은 ε 평균이 0이 아닌 상수 편향 때문이다. 학습 평균만 쓰는 상수 기준선이 이미 1.94%이고,
  모든 모델이 그 기준선보다 나쁘다. 텍스트 피처의 추가 설명력은 확인되지 않았다.
- 모델 B가 쓸모없다는 증명은 아니다. 이 피처(언급량·감성 z)와 이 설정으로는 신호를 찾지 못했다는 뜻이다.
