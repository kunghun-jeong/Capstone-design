# Capstone-design

매크로-텍스트 분해 구조를 활용한 미국 반도체 섹터 주가 예측 시스템 — 성균관대학교 캡스톤 디자인 수업
프로젝트 (팀 4명).

## 개요

가격 데이터뿐 아니라 뉴스와 Reddit 커뮤니티 여론을 결합해, 미국 반도체 섹터(SOXX 상위 10개 종목)의
시계열 주가를 예측하는 것을 목표로 한다. 핵심 아이디어는 예측 대상을 두 개의 모델로 분해하는 것이다.
종목 i의 t+h 시점 수익률은 다음과 같이 분해한다.

```
r_i,t+h = r_S,t+h + ε_i,t+h
```

- **모델 A — 섹터 타이밍**: 매크로 변수(금리, VIX, 유가, 달러인덱스 등, FRED 기준)를 입력으로 섹터
  ETF(SOXX/SMH)의 수익률 `r_S,t+h`를 예측하는 시계열 모델.
- **모델 B — 종목 선별**: 종목별 뉴스·Reddit 텍스트 + 기술지표를 입력으로, 섹터 대비 초과수익
  `ε_i,t+h`를 예측하는 횡단면 랭킹 모델.

매크로 변수는 같은 시점 모든 종목에 동일하게 적용되어 종목 간 우열을 가리는 데는 변별력이 없다 —
그래서 "섹터 전체의 방향"은 매크로(모델 A)가, "섹터 내 어느 종목이 상대적으로 더 오를지"는 텍스트
(모델 B)가 설명하도록 역할을 명확히 나눴다. 최종 예측값은 두 모델 출력의 합이다.

## 데이터

| 종류 | 소스 (후보) |
|---|---|
| 뉴스 | Alpha Vantage, Massive, Alpaca 뉴스, feedparser |
| 커뮤니티 | Reddit (게시물 like/조회수를 우선순위 가중치로 활용 검토 중) |
| 기술지표 | Alpha Vantage 또는 yfinance OHLCV 기반 계산 (RSI, 이동평균, 변동성 등) |
| 매크로 지표 | FRED (금리, VIX, 유가, 달러인덱스 등) |

텍스트 데이터는 뉴스/Reddit 게시물의 발행 시각과 실제 거래 가능 시점을 맞추는 시점 정합
(point-in-time alignment) 과정을 거쳐, 모델이 미래 정보를 미리 학습하지 않도록 한다.

## 평가

단계적 비교(ablation) 방식을 따른다.

1. 무조건 상승 예측
2. 가격·기술지표만 사용한 베이스라인(GBDT)
3. ②+매크로 모델(모델 A)
4. ③+텍스트 모델(모델 B) — 최종 모델

평가지표는 방향 적중률, IC(정보계수), 백테스팅 기반 수익률·Sharpe 비율. 학습·검증·테스트 구간은
시간순으로 분리(walk-forward)해 미래 데이터가 과거 예측에 섞이지 않게 한다.

모델 자체의 ablation(모델 B를 어떤 방법론으로 구현할지)도 별도로 진행 중이다 — FinBERT/SocBERT류
사전학습 인코더, 그 외 사전학습모델, 범용 LLM 프롬프트 엔지니어링 등 여러 방법론 후보를 병행 실험하며
비교할 예정이다.

## 현재 상태 (아직 미확정 / TBD)

- 정확한 패키지 목록·버전, 패키지 매니저
- 팀원별 역할 분담 (1단계 데이터는 전원 공동, 2단계부터 모델 A/B로 2명씩 분담 예정)
- 모델 B 최종 방법론
- Time plan (주차별 일정)

디렉토리 구조는 파이프라인 단계(데이터 → 피처 → 모델 A/B → 백테스팅) 순서를 반영해 확정했다 —
[`AGENTS.md`](./AGENTS.md#directory-structure) 참고.
